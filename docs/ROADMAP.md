# ROADMAP.md — 路线图(优先级由用户定)

## 下一波(用户已定)

### 1. 每日限时挑战
- 解锁:通过第 1 关(A1.1)后。
- 词条:**只用玩家已收集的动词**。
- 规则草案:每日一局(按日期种子,全玩家同盘)、限时(2–3 分钟)、复用现有计分引擎;本地最佳成绩存档;排名后端留接口(本期不做)。
- 入口:主菜单加" Dagelijkse uitdaging "按钮(未解锁置灰)。

### 2. 无尽模式
- 解锁:通过第 1 关后。
- 词条:只用已收集动词,池随分数扩大。
- 规则草案:无关卡目标,纯刷分;死局自动洗牌;结算进"最佳分"榜(按模式分键)。
- 复用:引擎、计分、横幅/朗读(无尽模式用中央闪现而非横幅——见 DESIGN.md §5)。

## 之后

### 3. 内容铺量(阶段二主体)
- 动词 A2+B1 共 60 词(NT2Lex / Taalboost / inburgering.org 分层,DutchGrammar 校验),插画补齐。
- 关卡表扩展:A1.x → B1.x,每关 4 词递进;解锁链现有逻辑直接支持。
- 同盘词形去重逻辑已有(组盘时避免两个激活动词出现相同字符串)。

### 4. 实验候选(用户拍板后再做)
- **四消**(原形+三变位同消):学习联结更强、难度上升;候选做法 = B1/高级模式规则,或同盘 A/B 对照版本。
- **原形百搭块**:随机出现的原形块可替代该动词缺的形式;娱乐性强但用户担心易混淆。
- 横幅时长做成设置项(当前 8s 硬编码)。

### 5. 打磨
- 音效层次(连击音阶、过关 jingle 已有雏形)。
- PWA/离线缓存(单文件已天然离线,加 manifest 即可装桌面)。
