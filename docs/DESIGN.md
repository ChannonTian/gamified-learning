# DESIGN.md — 设计决策与依据

> tile-match 的"为什么这么设计"。改玩法前先读;有新决策就追加。

## 1. 核心循环与学习原理

**问题**:教育游戏研究里的 "chocolate-covered broccoli" 批评——游戏机制和学习内容两张皮,效果差(Duolingo 配对模式的社区评价"像肌肉记忆游戏"是典型)。

**对策**:把检索练习做成消除的判定条件——匹配对象不是"三个相同的词",而是**同一动词的三种不同变位形式各一个**(单数过去式/复数过去式/过去分词)。每次消除前,玩家必须读词并回忆"这个词形属于哪个动词、是哪种形式"。消除后的原形展示是反馈闭环。

- 形式不齐(如 2×liep+1×liepen)→ 不消、静默弹回、无提示(用户明确要求不打断)。
- 4+ 连且三形式齐全 → 全消,连锁(cascade)计分放大。

## 2. 弱提示系统(可开关)

- **形状 = 变位类型**:圆角 = 单数过去式,近直角 = 复数,切角(非正六边形)= 过去分词。刻意做得微妙,防止退化成"找形状"游戏。
- **颜色 = 源动词**:同动词同色相,低饱和(浅色模式 L≈92%,深色模式 L≈26%)。
- 两者都可在设置关闭(关颜色 = 全中性灰;关形状 = 全圆角),自虐型学习者的选项。
- 棋盘上不画图例(用户判定无用),形状说明只存在于玩法介绍。

## 3. 棋盘与字号(手机优先)

- **4 列 × 9 行(16:27)**:列数决定词块宽度→字号。4 列让手机格子 ~90px、字号 ~18px;9 行吃满竖屏。总容量 36 块。
- **4:3 横向词块**:单词横向排列,宽扁块利用率最高。
- **统一字号按最长词 canvas 实测自适应**(`computeLevelFont`):不用字符数估算(会截断),保证任何词完整显示。
- 组盘:聚类偏置(新块 62% 概率复用邻块动词)+ 开局保底 ≥2 个可行组合 + 兜底"差一块"布局;无解自动洗牌(洗后同样保底)。

## 4. 计分与连击(无步数限制)

- 每块 10 分 × 连锁倍数(×2、×3…),棋盘上浮字。
- 连击 = 连续有效交换;**教学横幅显示的 8 秒就是连击倒计时**——横幅消失(超时或点按)连击清零,无效交换也清零。读卡与保连击天然一致。
- 每关最佳分入库(localStorage),菜单关卡卡显示。
- 无失败态:关卡目标 = 收集齐本关全部动词。

## 5. 教学呈现(三层)

1. **首次解锁(全局)**:全屏图鉴卡——插画 + 原形 + 三变位 + 点击展开释义,朗读四形。阻挡式,仪式感。
2. **普通关卡每次消除**:底部教学横幅(插画+原形+三变位+右侧释义),**不阻挡操作**,8 秒自动消失/点按关闭,同时朗读"原形→单数→复数→分词"(nl-NL,Web Speech API,音量可调)。横幅绝对定位覆盖操作坞(按钮+留白),绝不碰棋盘。
3. **词典图鉴**:按关卡分组,已收集动词可点回看卡片,右侧显示英文释义 + **累计消除次数**(记忆统计)。

未来无尽/每日模式不用横幅(用旧的中央闪现,代码保留 `#flash`)。

## 6. 课程与数据

- 现有 12 词 = A1.1(zijn/hebben/gaan/komen)、A1.2(zien/geven/nemen/eten)、B1.1(blijven/lopen/schrijven/slapen),每关 4 词。
- 分层依据:NT2Lex(CEFR 分级词库)、Taalboost 0–A2 词频、inburgering.org A2/B1 语法要求;词形以 nl.wikipedia 强变化动词表 + DutchGrammar 校验。
- 数据结构:`VERBS = {inf, sg, pl, pp, en, zh, hue, lv}`;`LEVELS = {id, verbs[], goal}`;插画 = `ART[inf](ctx)` 代码生成的 SVG(两套风格 A 扁平 / B 线稿,共享元素库:小人姿态/物件/动作线)。

## 7. 技术要点

- 单文件零依赖;DOM 词块 + CSS transform 动画;async/await 游戏循环;WebAudio 合成音效(音量可调)。
- 主题:CSS 变量(--paper/--card/--ink/--line/--tile-*),深色模式整站切换。
- i18n:`I18N` 词典(nl/zh)+ `data-i18n` 静态标记 + `t()` 动态;释义语言跟随界面语言(en/zh 字段都有)。
- 存档:`nlm3.prototype.v1`,merge 默认值保证向后兼容。
- 调试钩子 `window.NLM3` 供自动化测试。

## 8. 悬置的实验(用户拍板后再做)

- **四消**(原形+三变位同消):学习联结更强,但匹配显著变难、节奏变慢,需重调关卡密度。候选方案:B1/高级模式规则,或做 A/B 对照版本。
- **原形百搭块**:原形块随机出现,可替代该动词缺的任一形式参与消除。娱乐性好但用户担心易混淆。
