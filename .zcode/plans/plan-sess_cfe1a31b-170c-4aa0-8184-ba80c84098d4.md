# 荷兰语不规则动词三消 — 计划 v2(两阶段)

## 已确认的设计
- **匹配规则**:同行/列连续 ≥3 个同一动词,且单数过去式/复数过去式/过去分词各 ≥1 才消除;4+ 连且含全三种形式全消+加分;不全则静默弹回(无提示,不打断)。
- **提示系统**:形状=变位类型(圆角方/胶囊/六边形),颜色=源动词(同动词同色相、同盘色相拉开、低饱和保持淡);格子只显示词形,长词自动缩字号。
- **消融展示**:首次解锁 → 图鉴卡(插画+原形+点击展开英文释义),点击关闭;非首次 → 大字原形停留约 1s 自动淡出。
- **数据**:{inf, sg, pl, pp, cefr, art, gloss:{en}} — 释义默认英语,字段预留多语言扩展。

## 阶段 1:原型(本次实施)
1. **棋盘引擎**(8×8,全部核心逻辑):初始化(无预匹配+保证有解)→ 点选/拖拽交换 → 严格匹配扫描 → 静默弹回 → 消除+原形展示 → 重力下落 → 按动词×形式类型加权补牌(保持三形式均衡)→ 连锁 → 死锁检测+洗盘 → 提示按钮。
2. **动词**:10~12 个 A2 高频词(zijn, hebben, gaan, komen, zien, geven, nemen, blijven, lopen, eten, schrijven, slapen),2 个关卡(限定步数收集 N 个动词)。
3. **插画**:SVG 元素库(小人姿态/动作线/常用物件)+ 上述每词一幅;出 2 种风格样张供选。
4. **形状系统**(3 种变位形状)+ **色相系统**(低饱和)。
5. **消融展示**:首解锁卡 / 非首次大字闪现;图鉴雏形(按关卡列出已收集)。
6. localStorage 存进度。
7. **QA**:浏览器自动化模拟点击(交换、弹回、消除、连锁、过关),截图检查布局/动画/插画,console 无报错;然后交你试玩,重点反馈:插画风格选择、形状可读性、节奏手感。

## 阶段 2:全量(原型反馈后另起)
- 动词铺满 60 词(A2≈30/B1≈30,分层依据 NT2Lex、Taalboost 0–A2 词频、inburgering.org;词形按 DutchGrammar+nl.wikipedia 校验)+ 插画补齐。
- 12 关(A2×6+B1×6)、无尽模式(通关解锁)、每日限时挑战(第 3 关后解锁,日期种子,本地最佳,排名留接口)。
- 音效(WebAudio 合成)、打磨、完整 QA。
