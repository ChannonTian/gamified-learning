# Koppelen · demo(link-match-demo)

特别试玩版:只用 **Taalhuis 词表 NIG I–IV 的 50 个动词**(顺序即词表顺序)。

- **18 关纯序号(1–18)**:先全部单数过去式轮、再复数轮、最后过去分词轮;每关 8–9 词、一关一种词型、同屏零重复,开局 2 个随机空位降低难度。
- **zullen 没有过去分词**(词表注明),分词轮自动不含它;词卡也只展示存在的形态。
- 无尽 / 每日 / 生存模式只用这 50 词;存档独立(`linkmatchdemo.v1`),与主版互不影响。
- 单文件零依赖,双击即玩;线上地址 `/link-match-demo/`。
