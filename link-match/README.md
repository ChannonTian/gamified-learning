# Koppelen(link-match)— 荷兰语动词连连看

> 与 [tile-match](../tile-match/) 同一学习体系的独立产品:动词**原形 ↔ 变位形式**的经典连连看。

## 玩法

- **每关只练一种配对类型**:原形↔单数过去式 / 原形↔复数过去式 / 原形↔过去分词——三档(A1/A2/B1)各两轮三轮,共 **18 关**,顺序解锁。
- 每关 7 个动词 × 2 对 = **14 对**,布满 4×7 网格;点选原形块与同动词的对应变位块,路径**最多 2 个折角**(可绕棋盘外圈空白)即消除;无重力,消除后原位留空。
- 原形块有**橙色下划线**标记;变位块的形状 = 其形式(圆角/直角/切角,与三消一致的形状语言)。
- 配对成功 → 底部教学横幅(插画 + `lopen — liepen` + 朗读"lopen, liepen",倒计时即连击窗口,时长可在设置调 5-30s);计分:每对 +15,清盘 +100,窗口内连续配对有连击加成。
- 死局(无可连对)自动重排;闲置自动提示(高亮一组可连对,时长可调)。

## 模式

- **关卡**:9 关顺序解锁(见上)。
- **无尽模式**(过第 1 关解锁):只用**已收集的动词**,清盘自动发下一盘,连击窗口跨盘延续,纯刷分;最佳分实时保存。
- **每日挑战**(过第 1 关解锁):180 秒倒计时,当日日期种子决定盘面(同日同盘);每天限完成一次,完成后菜单带 ✓,当日最佳分入档。

## 运行 / 部署

与全仓一致:单文件零依赖,双击即玩;push 到 main 后 GitHub Pages 自动发布,地址 `/link-match/`。

## 与 tile-match 的关系

**独立产品、互不依赖**:词库数据、插画元素库(小人/道具/场景表)、主题与 i18n 框架从 tile-match 拷贝而来,两侧各自演化。⚠️ 若修改动词变位/释义或插画元素库,需**同步两个文件**。
