# Koppelen(link-match)— 荷兰语动词·名词连连看

> 与 [tile-match](../tile-match/) 同一学习体系的独立产品:动词**原形 ↔ 变位**、名词**单数 ↔ 冠词/复数**的经典连连看。

## 玩法

- **五组关卡,组内按形式分关,互不锁关、可分别开始**:
  - **Voornaamwoorden(3 关)**:人称代词 ik ↔ 宾格/物主/反身(mij / mijn / mezelf);
  - **Persoonsvormen(9 关)**:A1 动词现在时人称,磁贴带上人称(gaan ↔ **ik ga** / hij gaat / wij gaan);
  - **Lidwoorden de/het(4 关)**:名词 ↔ 冠词+名词(boek ↔ het boek),**de/het 混在一盘**;相邻两关为一组:前一关名词磁贴带冠词提示(**de dag - dag**),下一关裸词(36 个 A1/A2 高频名词,冠词经 Onze Taal 官方 het-words 词表核对);
  - **Meervouden(4 关)**:单数 ↔ 复数 -en / -s / -'s(boek ↔ boeken;tafel ↔ tafels;auto ↔ auto's);
  - **Verleden tijd A1–C1(54 关)**:148 个动词的过去时单数 → 复数 → 过去分词。
- 闯关:**4×5 盘,9 词×1 对(同屏零重复)+ 开局 2 个随机空位**;挑战模式:**4×9 盘,9 词×2 对=18 对**。点选原形块与同词的对应形式块,路径**最多 2 个折角**(可穿空格、绕棋盘外圈)即消除;无重力,消除后原位留空。
- 原形块有**橙色下划线**标记;形式块的形状 = 其类型(圆角/方角/叶形,两主题一致)。
- 配对成功 → 横幅展示词卡(动词四形态 / 名词单复数两形态,当前词型高亮)+ 朗读;倒计时即连击窗口(默认 15s,可调 5-30s)。计分:每对 +15,清盘 +100,窗口内连续配对有连击加成。
- 死局(无可连对)自动重排;闲置自动提示(高亮一组可连对,时长可调)。

## 模式

- **关卡**:74 关,**每组独立顺序解锁**(组内打完一关开下一关,组间互不影响)。
- **无尽模式**(过任意一关解锁):只用**已收集的动词**,清盘自动发下一盘,连击窗口跨盘延续,纯刷分;最佳分实时保存。
- **每日挑战**(过任意一关解锁):180 秒倒计时,当日日期种子决定盘面(同日同盘);每天限完成一次,完成后菜单带 ✓,当日最佳分入档。
- **生存模式**(过任意一关解锁):每次配对成功续命 15 秒,点错不失败但超时即结束;计时 ≤5s 变红脉冲;最佳分入档。

## 运行 / 部署

与全仓一致:单文件零依赖,双击即玩;push 到 main 后 GitHub Pages 自动发布,地址 `/link-match/`。

## 与 tile-match 的关系

**独立产品、互不依赖**:词库数据、插画元素库(小人/道具/场景表)、主题与 i18n 框架从 tile-match 拷贝而来,两侧各自演化。⚠️ 若修改动词变位/释义或插画元素库,需**同步两个文件**。
